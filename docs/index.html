Why Use Decant?

🔒

100% Private & Client-Side

All DOM parsing, HTML extraction, and Markdown formatting happen 100% locally in your browser. Zero tracking, zero telemetry.

⚡

Manifest V3 Native

Built with background service workers, content script dynamic loaders, and side panels for maximum speed and browser compatibility.

🟣

1-Click PKM Handoff

Export directly to Obsidian, Logseq, Bear, NotePlan, or Drafts using native URI protocol schemes with customizable vaults.

🤖

AI Handoff Integration

Send decanted articles directly to ChatGPT, Claude, Gemini, DeepSeek, or Perplexity with pre-formatted summary prompts.

⚙️

Custom YAML Templates

Tailor your frontmatter variables (title, author, source URL, date, tags) and configure Turndown Markdown rules.

⌨️

Keyboard & Context Menus

Use hotkeys (Alt+Shift+D or Alt+Shift+C) or right-click context menu options to clip tabs or selections instantly.
