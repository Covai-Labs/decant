Questions, answered

Frequently asked

How is Decant different from Firefox’s / Safari’s built-in Reader Mode?

Reader Mode reformats for reading but does not give you the content. Decant extracts the article into clean, reusable Markdown and hands it to your note-taking app, clipboard, or downloads.

How does Decant compare to MarkDownload or MarkDownload forks?

Decant adds multi-tab batch clipping to ZIP, one-click PKM URI hand-off with frontmatter, a preview studio with math and code highlighting, and multiple export formats — all behind the same zero-telemetry, local-only architecture.

How is Decant different from SingleFile?

SingleFile preserves a pixel-faithful snapshot by inlining the whole page. Decant is the opposite by design: it strips the chrome and exports the extractable content as structured Markdown you can reuse, tag, and search.

Does Decant send my clipped pages anywhere?

No. Extraction runs entirely in your browser via local Mozilla Readability. Nothing you clip is uploaded; the extension requests only the permissions it needs to read, copy, download, and hand content to local apps.

Which browsers are supported?

Decant is a Manifest V3 extension built with WXT, available for Chrome, Edge, Brave, and Firefox.
