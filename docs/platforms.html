Web articles

Target Parser Strategy Notes
Generic Web Article ArticleParser
decant-core/article
Readability + Defuddle + Article-Extractor Runs three extractors concurrently and arbitrates by content-quality scoring.
Maintenance is the point. “DOM” parsers target semantic structure, not pixel positions; “internal API” parsers read the same RPC payloads the frontend uses. When a platform changes, one shared fix heals every consumer. If a parser drifts, add a fixture and open a PR — see Contributing.
